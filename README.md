Diwali Sales Analysis (Python EDA)
- Overview

This project performs Exploratory Data Analysis (EDA) on Diwali sales data to understand customer purchasing behavior and identify key sales trends during the festive season using Python.

- Objective

Analyze customer demographics and spending patterns

Identify top-performing states and product categories

Generate business insights from sales data

- Tech Stack

Python

Pandas

NumPy

Matplotlib

Seaborn

Colab

 - Project Steps

1. Data Loading using Pandas

2. Data Cleaning & Preprocessing

3. Exploratory Data Analysis (EDA)

4. Data Visualization for trend analysis

- Key Insights

1. Female customers contributed more to total sales

2. Age group 26–35 showed the highest purchasing power

3. Top states: Uttar Pradesh, Maharashtra, Karnataka

4. Most popular categories: Food, Clothing, Electronics

- Business Recommendations

1. Target high-spending age group (26–35) with festive campaigns

2. Focus inventory on top-selling product categories

3. Increase promotions in high-revenue states
